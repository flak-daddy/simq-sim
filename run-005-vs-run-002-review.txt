2. METHOD: A BLIND BASELINE
---------------------------
The same mechanical wheel was run on both runs' exact price paths under each pricing
version: every Monday sell a put 10% (or 15%) below spot with all free cash, hold to
Friday, and if assigned sell a covered call each Monday at the higher of the lot's cost
or 5% above spot. Cash earns 4%. It never reads headlines and never manages midweek.
What it earns is what the path and pricing hand out; the gap to your result is your
contribution.

3. THE PATH: RUN 2'S WAS FAR BETTER FOR A PUT SELLER
---------------------------------------------------
On the same pricing (v3), a blind 10% wheel made +100.7% on Run 2's path and +54.2% on
Run 5's; a blind 15% wheel made +51.8% against +43.8%.

That is surprising given Run 2 used the harsher market v1, under which a blind wheel
loses about 21% in a typical year. Run 2's path was an outlier in a good way for sellers:
  - SimQ rose 44% in the first half (to $92), then gave it back to finish flat. Big
    swings that end where they started pay put sellers repeatedly without leaving them
    holding losing shares at the end.
  - 42 of 52 weeks were chop, selloff, crash or rebound. Those regimes carry higher
    implied vol, so premiums were richer: a Monday put 10% below spot averaged 1.75% of
    strike on Run 2's path against 1.33% on Run 5's (same pricing v3).
  - Run 5's path started with a W2-W5 selloff and crash sequence (SimQ $63.80 to $24.37,
    -62%, by W5),
    which no put seller escapes cleanly, and its second half was a steady climb, where
    puts expire but premiums are thin (calm_up implied vol is the lowest).

Under market v1 with pricing v2, Run 2's +59% sits around the 91st percentile of 600
random years for a blind wheel. Under market v2 with pricing v3, Run 5's +52% sits around
the 83rd (10% wheel) to 98th (15% wheel) percentile. Both were good years, Run 2's more
unusually so for its model.


4. PRICING: IT FAVORED RUN 2, NOT RUN 5
---------------------------------------
Pricing v3 (Run 5) pays about 15% less than pricing v2 (Run 2) for the same put:
  Monday put 10% below, Run 2 path: v2 2.04% vs v3 1.75% of strike
  Monday put 10% below, Run 5 path: v2 1.58% vs v3 1.33% of strike
On Run 2's path that difference is worth 13-21 points of blind-wheel return over the
year; on Run 5's path, 7 points. So Run 2 had both the better path and the richer
pricing.

6. IS THE MODEL TILTED TOWARD PROFIT?
-------------------------------------
Under the current model (market v2/v3, pricing v3) yes: a blind 10% wheel makes a median
of about +21-24% a year and beats cash about 70% of the time. Under Run 2's model
(market v1, pricing v2) it was the opposite: median about -21%, beating cash about a
third of the time. Run 2's +59% therefore came from an unusually seller-friendly path in
a model that was hostile on average, while Run 5's +52% came from a good path in a model
that is friendly on average.


7. ANSWERS
----------
Which run was better? Run 2 by result (+59.0% vs +52.1%, smaller drawdown). Run 5 by
play: relative to what a mechanical rule earned on each path, you were roughly even to
+8 points in Run 5, and 6 to 63 points behind in Run 2.

Was it the seed? For both runs, the path explains most of the result. Run 2's path was
exceptionally good for put sellers (a 44% rise and full round trip with lots of high-vol
weeks); Run 5's path was good but front-loaded with a crash sequence.

Was it the pricing? Pricing helped Run 2, not Run 5: v2 premiums were about 15% higher
than v3.

Did you make better moves? Yes, in Run 5 relative to its environment, mainly through
first-half damage control. The full-year +52% still matched a blind rule on the same path,
so the honest read is: good process, average-to-good result for this model and path.

A fair yardstick for future runs is your result against the blind 10% and 15% wheels
on the same path (wheel_compare.py RUN computes both).

Caveats: one path per run is a small sample; the blind wheel puts all free cash into
one strike each Monday, which is more aggressive than your sizing.
